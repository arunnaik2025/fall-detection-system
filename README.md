# fall-detection-system
Fall Detection System for Elders and Patients using C++ with SMS alert notification to emergency contacts
##  About
This project is a Fall Detection System designed to monitor elders and patients. It detects sudden falls and sends an SMS alert to emergency contacts for quick response and safety.


## ⚙️ How it Works
1. The system continuously monitors movement using sensors.
2. When a sudden fall is detected, the system triggers an alert.
3. A GSM module is used to send an SMS notification.
4. The message is sent to a predefined mobile number.
5. This helps caregivers respond quickly in emergency situations.

## How to Run
1. Connect the required hardware components (sensors, GSM module).
2. Upload the C++ code to the microcontroller/system.
3. Ensure the GSM module has a valid SIM card.
4. Power ON the system.
5. When a fall is detected, an SMS alert will be sent automatically.


##  Technologies Used
1. C++
2. GSM Module (for SMS alerts)
3. Sensors (for fall detection)
